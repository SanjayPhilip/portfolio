# 🚀 ClipFlow

> A lightweight, smart clipboard manager that runs in your system tray. Never lose what you copied.

[![Python](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Code style: black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)

## ✨ Features

- 📋 **Clipboard History** — Automatically saves everything you copy
- 🔍 **Quick Search** — Find any copied item instantly
- 📌 **Pin Favorites** — Keep important clips always accessible
- 🏷️ **Tags & Categories** — Organize your clipboard items
- 🤖 **AI Transformations** — Summarize, translate, and format text (coming soon)
- 🎨 **Dark/Light Themes** — Easy on the eyes, day or night
- ⌨️ **Global Hotkeys** — Open history without touching your mouse

## 🛠️ Tech Stack

- **Python 3.10+**
- **PyQt6** — Cross-platform GUI
- **SQLite** — Local, zero-config database
- **Ollama** — Local AI for text transformations (optional)

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/clipflow.git
cd clipflow

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the application
python -m clipflow
```
